# 智流商城 ZhiFlow：開源 Java 商城系統

[简体中文](README.md) | **繁體中文** | [English](README.en.md) | [日本語](README.ja.md)

智流商城（ZhiFlow）是一套開源的 Java 商城系統原始碼。本儲存庫是智流商城開源版的後端主儲存庫，基於 JDK 25、Spring Boot 4、Spring Security 7、PostgreSQL、Valkey、Vue 3 和 uni-app 開發，面向單店鋪商城場景，包含商品、規格 / SKU、購物車、訂單、微信支付、支付寶、會員、權限、內容和統計等基礎能力，可以用來學習、選型評估、二次開發，也可以直接架設自營商城。

如果你正在找 Java 商城系統、商城原始碼或電商系統原始碼，可以先從這裡看智流商城的開源實現。需要多店鋪、多租戶 SaaS、行銷和分銷、跨境電商、線上問診這類醫療場景，或者需要多端交付、商業技術支援時，請看下文「授權與版本」。

## 專案說明

- **專案名稱**：智流商城 ZhiFlow，Java 商城系統、商城原始碼、電商系統原始碼
- **專案簡介**：智流商城開源版是商用平臺「智流 · 開店引擎」的開源發行版，程式碼來自線上長期執行的商城系統，不是為開源專門寫的示範專案
- **業務形態**：單店鋪商城，包含管理後台和 H5 商城
- **技術說明**：後端 JDK 25 + Spring Boot 4.1.1 + Spring Security 7.1.1，前端 Vue 3 + uni-app；具體依賴版本以後端 `pom.xml` 和前端 `package.json` 為準
- **部署形態**：模組化單體，後端打成一個 jar，必需的外部元件只有 PostgreSQL 和 Valkey（或 Redis）
- **開源授權**：AGPL-3.0，適合學習、評估和符合協議的使用場景
- **商業授權**：閉源商用、私有化交付、商業技術支援和完整業務版本，見「授權與版本」
- **商業版本**：標準版、跨境版、醫療版，具體功能和服務以商務合同為準
- **相關連結**：原始碼儲存庫地址見「相關資料」

## 專案特點

- JDK 25 + Spring Boot 4 + Vue 3，前後端分離
- 模組化單體，一個 jar 部署，不需要註冊中心和設定中心
- Spring Security 7 認證授權，內建 OAuth2 授權伺服器
- PostgreSQL 資料庫，Valkey / Redis 快取，Redisson 分散式鎖
- 接入微信支付、支付寶真實通道，不是模擬支付
- 支付單、訂單雙狀態機，回呼後主動查單，對不上的記錄進差錯池
- 模組之間只走介面契約，ArchUnit 在測試階段攔截越界依賴
- AGPL-3.0 開源，商業授權和商業版本見「授權與版本」

## 技術版本說明

智流商城開源版直接用 JDK 25 和 Spring Boot 4.1 構建，Spring Security 7、Tomcat 11、PostgreSQL 18 都是當前主線版本，適合新專案評估和長期維護。還停在舊版本框架上的商城系統，後面要花在框架升級、依賴相容和安全修補上的成本通常更高。

## 文件與快速啟動

完整的部署、上線、升級與本地開發說明見後端儲存庫 README：https://github.com/zhiliumall/zhiflow#readme

### Docker Compose 一鍵啟動

需要 Docker 24+ 與 Docker Compose v2.24+。三個儲存庫並排複製到同一個目錄下：

```bash
mkdir zhiflow-mall && cd zhiflow-mall
git clone https://github.com/zhiliumall/zhiflow.git
git clone https://github.com/zhiliumall/zhiflow-admin.git
git clone https://github.com/zhiliumall/zhiflow-uniapp.git
cd zhiflow
./scripts/init-env.sh
docker compose up -d --build
```

首次啟動自動建表；管理員 `admin` 的初始密碼隨機產生，用 `docker compose logs app | grep -A4 首次启动` 檢視，首次登入會要求改密碼。
開啟 `http://localhost/` 是 H5 商城，`http://localhost/admin/` 是管理後台。

正式上線前，請按後端 README「上线：域名与 HTTPS」一節設定，並用自己的商戶號在沙箱環境測通支付與回呼。

## 常見問題

**智流商城是什麼？**

智流商城是一套開源的 Java 商城系統，後端用 Spring Boot 4，管理後台用 Vue 3，H5 商城用 uni-app。本儲存庫是開源版主儲存庫，開源版是單店鋪商城，從商品上架到使用者收貨的整條交易鏈路都能用。

**智流商城開源版可以免費使用嗎？**

可以，前提是遵守 AGPL-3.0。最要緊的一條：改過的程式碼如果對外提供網路服務，就要把原始碼開放給使用者。專案不適合 AGPL-3.0 的話，可以聯絡商務諮詢瞭解商業授權。

**能直接拿來開網店嗎？**

可以。開源版支援微信支付和支付寶，在微信裡開啟 H5 就能下單。正式收款前，請用自己的商戶號在沙箱環境把支付和回呼完整測一遍。

**已經付款的訂單怎麼退款？**

開源版目前沒有退款功能，需要退款時請到微信支付或支付寶的商戶後台操作。v1.1 計畫提供未出貨訂單整單原路退款和基礎運費（固定運費、滿額免運）；退貨退款等完整售後流程在商業版裡。

**為什麼開源版沒有優惠券和售後？**

開源版只放交易主鏈路，程式碼更容易讀，二次開發也更乾淨。優惠券、積分、售後和訂單算價、支付退款綁得很緊，要放就得整套放，所以統一放在商業版。需要的話可以在開源版上自己開發，也可以直接用商業版。

**為什麼不用微服務？**

中小團隊上微服務，大半精力會花在運維上。開源版把業務模組聚合成一個 jar，模組之間用介面契約呼叫，邊界還在，部署和排查都簡單得多。

**智流商城支援 Spring Boot 4 和 Vue 3 嗎？**

支援。後端基於 JDK 25 和 Spring Boot 4.1，前端基於 Vue 3 和 uni-app，具體依賴版本以後端 `pom.xml` 和前端 `package.json` 為準。

**支援小程式和 App 嗎？**

開源版只發布 H5。微信小程式、App 和 PC 商城在商業版裡。

**商業版有哪些版本？**

三個版本，都支援私有化部署：

- 標準版：多店鋪、多租戶 SaaS、行銷、分銷、客服、小程式和 App 等多端
- 跨境版：在標準版基礎上，加多幣種、多語言、跨境支付與結算、跨境稅費，適合出海賣貨
- 醫療版：在標準版基礎上，加線上問診、視訊問診、問診即時字幕與翻譯、線上處方，適合網路醫院和醫藥電商

**商業版原始碼怎麼交付？**

商業版的交付方式、授權期限和售後服務，以商務合同為準。

**智流商城適合哪些商城專案？**

本開源儲存庫適合自營的單店鋪商城、Java 商城系統學習、商城原始碼評估、二次開發和原型建設。多店鋪入駐、多租戶 SaaS、跨境電商、網路醫療和私有化交付，請看商業版的標準版、跨境版和醫療版。
