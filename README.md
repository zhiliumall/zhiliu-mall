# 智流商城 ZhiFlow：开源 Java 商城系统

智流商城（ZhiFlow）是一套开源的 Java 商城系统源码。本仓库是智流商城开源版的后端主仓库，基于 JDK 25、Spring Boot 4、Spring Security 7、PostgreSQL、Valkey、Vue 3 和 uni-app 开发，面向单店铺商城场景，包含商品、规格 / SKU、购物车、订单、微信支付、支付宝、会员、权限、内容和统计等基础能力，可以用来学习、选型评估、二次开发，也可以直接搭建自营商城。

如果你正在找 Java 商城系统、商城源码或电商系统源码，可以先从这里看智流商城的开源实现。需要多店铺、多租户 SaaS、营销和分销、跨境电商、在线问诊这类医疗场景，或者需要多端交付、商业技术支持时，请看下文「授权与版本」。

## 项目说明

- **项目名称**：智流商城 ZhiFlow，Java 商城系统、商城源码、电商系统源码
- **项目简介**：智流商城开源版是商用平台「智流 · 开店引擎」的开源发行版，代码来自线上长期运行的商城系统，不是为开源专门写的演示项目
- **业务形态**：单店铺商城，包含管理后台和 H5 商城
- **技术说明**：后端 JDK 25 + Spring Boot 4.1.1 + Spring Security 7.1.1，前端 Vue 3 + uni-app；具体依赖版本以后端 `pom.xml` 和前端 `package.json` 为准
- **部署形态**：模块化单体，后端打成一个 jar，必需的外部组件只有 PostgreSQL 和 Valkey（或 Redis）
- **开源授权**：AGPL-3.0，适合学习、评估和符合协议的使用场景
- **商业授权**：闭源商用、私有化交付、商业技术支持和完整业务版本，见「授权与版本」
- **商业版本**：标准版、跨境版、医疗版，具体功能和服务以官网和合同为准
- **相关链接**：官网、版本对比、在线演示、项目文档，见「相关资料」

## 项目特点

- JDK 25 + Spring Boot 4 + Vue 3，前后端分离
- 模块化单体，一个 jar 部署，不需要注册中心和配置中心
- Spring Security 7 认证授权，内置 OAuth2 授权服务器
- PostgreSQL 数据库，Valkey / Redis 缓存，Redisson 分布式锁
- 接入微信支付、支付宝真实渠道，不是模拟支付
- 支付单、订单双状态机，回调后主动查单，对不上的记录进差错池
- 模块之间只走接口契约，ArchUnit 在测试阶段拦截越界依赖
- AGPL-3.0 开源，商业授权和商业版本见「授权与版本」

## 技术版本说明

智流商城开源版直接用 JDK 25 和 Spring Boot 4.1 构建，Spring Security 7、Tomcat 11、PostgreSQL 18 都是当前主线版本，适合新项目评估和长期维护。还停在旧版本框架上的商城系统，后面要花在框架升级、依赖兼容和安全修补上的成本通常更高。

### 本地运行

先准备好：JDK 25、Maven、Node.js、PostgreSQL 18、Valkey 9.0 或 Redis。MeiliSearch 和 MinIO 第一次跑可以不装。

1. 拉取代码

```bash
git clone https://github.com/zhiliumall/zhiflow.git
git clone https://github.com/zhiliumall/zhiflow-admin.git
git clone https://github.com/zhiliumall/zhiflow-uniapp.git
```

2. 初始化数据库：按 `doc` 里的说明，执行 `db` 目录下的建表脚本和初始数据。
3. 改后端配置：在 `application.yml` 里填数据库和 Valkey（或 Redis）的连接信息。支付配置可以先空着，不影响浏览和下单。
4. 启动后端：运行 `zhiflow-boot` 模块，默认端口 8080。
5. 启动前端：两个前端仓库分别执行 `npm install` 和 `npm run dev`，把接口地址指向后端。

初始管理员账号和密码在文档里，第一次登录会要求改密码。

### Docker 部署

用 Docker Compose 可以一次把后端、前端、数据库和缓存都跑起来，步骤见 `doc` 里的部署说明。

正式上线前，请把文档里的上线检查清单逐项过一遍，尤其是微信支付和支付宝的沙箱联调。

## 常见问题

**智流商城是什么？**

智流商城是一套开源的 Java 商城系统，后端用 Spring Boot 4，管理后台用 Vue 3，H5 商城用 uni-app。本仓库是开源版主仓库，开源版是单店铺商城，从商品上架到用户收货的整条交易链路都能用。

**智流商城开源版可以免费使用吗？**

可以，前提是遵守 AGPL-3.0。最要紧的一条：改过的代码如果对外提供网络服务，就要把源码开放给用户。项目不适合 AGPL-3.0 的话，可以通过官网了解商业授权。

**能直接拿来开网店吗？**

可以。开源版支持微信支付和支付宝，在微信里打开 H5 就能下单。正式收款前，请用自己的商户号在沙箱环境把支付和回调完整测一遍，再按上线检查清单逐项核对。

**已经付款的订单怎么退款？**

开源版没有售后退款功能，需要退款时请到微信支付或支付宝的商户后台操作。系统内的售后流程在商业版里。

**为什么开源版没有优惠券和售后？**

开源版只放交易主链路，代码更容易读，二次开发也更干净。优惠券、积分、售后和订单算价、支付退款绑得很紧，要放就得整套放，所以统一放在商业版。需要的话可以在开源版上自己开发，也可以直接用商业版。

**为什么不用微服务？**

中小团队上微服务，大半精力会花在运维上。开源版把业务模块聚合成一个 jar，模块之间用接口契约调用，边界还在，部署和排查都简单得多。

**智流商城支持 Spring Boot 4 和 Vue 3 吗？**

支持。后端基于 JDK 25 和 Spring Boot 4.1，前端基于 Vue 3 和 uni-app，具体依赖版本以后端 `pom.xml` 和前端 `package.json` 为准。

**支持小程序和 App 吗？**

开源版只发布 H5。微信小程序、App 和 PC 商城在商业版里。

**商业版有哪些版本？**

三个版本，都支持私有化部署：

- 标准版：多店铺、多租户 SaaS、营销、分销、客服、小程序和 App 等多端
- 跨境版：在标准版基础上，加多币种、多语言、跨境支付与结算、跨境税费，适合出海卖货
- 医疗版：在标准版基础上，加在线问诊、视频问诊、问诊实时字幕与翻译、在线处方，适合互联网医院和医药电商

**商业版源码怎么交付？**

商业版的交付方式、授权期限和售后服务，以官网说明和商务合同为准。

**智流商城适合哪些商城项目？**

本开源仓库适合自营的单店铺商城、Java 商城系统学习、商城源码评估、二次开发和原型建设。多店铺入驻、多租户 SaaS、跨境电商、互联网医疗和私有化交付，请看商业版的标准版、跨境版和医疗版。
